# Розклад (PWA)

Мобільний розклад занять групи. Працює як додаток на телефоні: можна додати на головний екран, відкривається без інтернету.

## Структура

Усі файли лежать в одній папці, `index.html` має бути в корені репозиторію.

```
├── index.html      головна сторінка: шапка, розклад, вікна, екран входу
├── info.js         ОГОЛОШЕННЯ для вкладки «Інформація» (редагуєш коли треба)
├── style.css       вигляд: кольори, розміри, теми, анімації
├── app.js          показ розкладу, тижні, вікна
├── rozklad.js      РОЗКЛАД НА МІСЯЦЬ + дзвінки (редагуєш щомісяця)
├── profil.js       дані профілю: ПІБ, роль, група, курс
├── dostup.js       назва на екрані входу
├── vhid.js         вхід однією кнопкою «ВХІД», без пароля
├── settings.js     налаштування: тема, розмір тексту, аудиторії
├── sw.js           офлайн-режим (лежить у корені)
├── manifest.json   назва й іконки для екрана телефона
├── icon-180/192/512.png   іконки додатка
├── server.py       локальний сервер для перевірки (необов'язково)
├── start.bat       запуск server.py двома кліками на Windows (необов'язково)
└── .gitignore      список файлів, які Git не бере
```

## Що редагувати

| Файл | Що робити | Як часто |
|------|-----------|----------|
| `rozklad.js` | Розклад, канікули, заліки, «Уточнення» для інших місяців | щомісяця |
| `info.js` | Додаєш або видаляєш оголошення | коли треба |
| `profil.js` | Текст у лапках | рідко |
| `dostup.js` | Назва на екрані входу | рідко |
| `sw.js` | Збільшуєш номер версії після кожної зміни | щоразу |
| Решта файлів | Не чіпати, якщо не хочеш змінити вигляд чи логіку | майже ніколи |

### Розклад (`rozklad.js`)

Пара записується так:

```js
["Назва", "4 пара", "18", "Викладач", "Примітка"]
```

Обов'язкові лише назва й номер пари. Час підставиться автоматично з `DZVINKY`. Число перед дужкою — день місяця. Дня немає у списку, отже його не видно. День без пар: `[]`.
Для нового місяця зміни `MISYATS` (рік і місяць) та список днів.

**Особливі дні** (у `rozklad.js`, замість списку пар):

```js
24: "Канікули",                          // ВІДПОЧИНОК (канікули)
25: "",                                    // просто ВІДПОЧИНОК
15: { nota: "ЗАЛІК", pary: [ ["Інформатика і КТ", "4 пара", "4", "Викладач"] ] },
16: { nota: "ЗАЛІК з права" },             // день без пар, але з позначкою
```

**Інші місяці** (блок `INSHI_MISYACI`): розкладу ще нема — `{ rik: 2026, misyac: 12, utochnennya: "Розклад уточнюється" }`, з'явився — заміни `utochnennya` на `dni: { ... }`.

**Примітка до тижня** (блок `TYZHNI`): `{ data: "2026-12-14", tekst: "Залікова сесія" }` — покаже плашку над днями цього тижня.

### Інформація (`info.js`)

Вкладка «Інформація» плавно виїжджає збоку. Одне оголошення — один блок `{ ... }` у списку `INFO`. Нове додавай зверху, непотрібне видаляй. Важливе (червоне): `vazhlyve: true`. Готовий шаблон лежить у коментарі на початку файлу.

### Вхід

Одна кнопка **ВХІД**, без пароля (екран входу плавно зникає, відкривається розклад). Додаток запам'ятовує вхід на цьому пристрої. Вийти можна з профілю.
Це не захист: репозиторій публічний, тож дані розкладу видно в самому GitHub. Не пиши в файли особисті дані.

## Як оновити сайт після змін

1. Зміни потрібні файли (`rozklad.js`, `info.js`).
2. У `sw.js` збільш номер: `rozklad-v2` → `rozklad-v3`, потім `v4` і так далі.
3. На GitHub відкрий файл, натисни ✏️, внеси зміни й натисни **Commit changes**. Або завантаж змінені файли: **Add file → Upload files**.
4. Через 1–2 хвилини сайт оновиться. Якщо на телефоні старе, закрий і відкрий додаток ще раз.

## Публікація на GitHub Pages

1. Зайди на github.com, створи акаунт або увійди.
2. **+ → New repository**. Назва, наприклад, `rozklad` (вона потрапить в адресу). Постав **Public**. На безкоштовному акаунті Pages працює лише з публічними репозиторіями. Натисни **Create repository**.
3. **Add file → Upload files**. Розпакуй архів, виділи **весь вміст** папки (не саму папку) і перетягни у вікно браузера. `index.html` має опинитись у корені. Натисни **Commit changes**.
4. **Settings → Pages → Build and deployment → Source: Deploy from a branch**. Branch: `main`, папка `/ (root)`, потім **Save**.
5. Через 1–2 хвилини зверху сторінки Pages з'явиться адреса:
   `https://ТВІЙ_НІК.github.io/rozklad/`

Файл `.gitignore` починається з крапки й на Windows чи Mac часто прихований. Якщо він не завантажився, нічого страшного.

## Поставити як додаток

- **iPhone (Safari):** Поділитись → «На початковий екран».
- **Android (Chrome):** меню ⋮ → «Встановити додаток».

## Перевірка на комп'ютері

Windows: двічі клікни `start.bat`. Інакше: `python server.py`. Відкриється `http://localhost:8000`.

## Якщо щось не працює

- **Помилка 404:** перевір, що `index.html` лежить у корені репозиторію, а не всередині папки. Зачекай ще кілька хвилин.
- **Старий розклад на телефоні:** переконайся, що збільшив версію в `sw.js`, і перезапусти додаток.
- **Порожній екран із назвою:** натисни **ВХІД**.
